
# 原生爆炸图专项工作流

1. 校验来源与依赖哈希。现有原生零件可直接用于装配。已有单一已爆炸的扁平装配及匹配引用可进二维出图入口。来源是 STEP 时，先保留原始文件并明确原生可编辑性与导入几何的边界。
2. 按已确认轴线、接合方向和配合整理拆解顺序。拆紧固件、解除轴向约束，再移出适当的端盖与外壳。可指定多件作为一个步骤。检查工艺、螺纹、卡扣、弹簧预压力和隐藏紧固件等难以由几何证明的事项。
3. schema 2 的 `assembly` 增加 `explode` 行，字段为 `id`、`operation`、`components`、`axis_component`、`direction`、`distance_mm`。方向取 `±x`、`±y`、`±z`，通过指定基准件的直边识别，也可用 `axis_diameter` 选择 Z 向同轴圆柱。位置以首个固定基准件的原点为参照。经确认采用预定位的紧固件可设 `fixed: true`。浮动件须提供明确配合。
4. 轻量模式可以只运行装配作业，保留原生爆炸和折合验收。标准模式再提交引用装配的 `drawing` 作业，生成二维爆炸轴测视图与 BOM。完整模式增加哈希验收、PDF 实际渲染、预览目检和打包。已有同参数且源代码、文件与校验记录均匹配时优先命中缓存。
5. 最终包络检查使用折合态原生部件包络及实测位移，出现相交时阻断交付。全过程净空、遮挡和运动顺序还需要核对。最终看图与工程判断分开记录。旧版路径线故障及其他边界见 [遗留项](V04_OPEN_ITEMS.md)。
