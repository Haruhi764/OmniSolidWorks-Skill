# SolidWorks 增量作业

适用本轮本机 SolidWorks 2014 x64 SP0，COM 22.0.0。先在项目 Git 根目录查看检查点。只读检查无需连接 CAD。

```powershell
python -B scripts/sw_supervisor.py run-20261125-1900 drawing-r1 --dry-run
```

可将阶段名换为 `smoke`、`explode-capture`、`explode`、`drawing`、`drawing-r2` 或 `regression`。查看相应阶段的 `job_state.json` 可读到宿主 PID、上次成功、尝试次数、原生错误和流程时间点。运行命令省略 `--dry-run`。已核验结果在输入及产物哈希一致时直接返回。每阶段的作业和代码版本指纹保留在 `plans`，有意修改参数或代码的修复应采用新的阶段或运行目录。

- 原生子进程使用既有 STA 桥接，以实际 COM 版本、可执行路径、空文档和 PID 进行二次绑定。运行复用用户已启动的宿主。失去连接、超时和无原生证据时封存 `partial` 并锁定该宿主，最多允许一次短暂 RPC 忙碌退避重试。本轮现有会话均为共享会话，未调用宿主退出、重启或终止。程序的超时清理只针对自己创建的 STA 帮助进程。
- 每阶段启动前记录配额、哈希及状态。原生通过后校验保存重开证据和文件哈希，再原子提升隔离目录，保留相对引用。发布窗口中断可凭已验收哈希恢复。若在原生执行中断、作业仍标记为 `running`，先检查原生错误、省略危险的宿主重启操作，确认宿主身份和文档状态后以验证过的检查点另启运行。保留原失败日志。
- `sw_reducer_incremental.py <运行名> capture|explode|drawing` 筹备本轮的减速器任务。通用的扫掠和可见性算法从实测组件包络和显式装配轴推导。缺乏方向证据时要求确认。端面啮合、全过程实体穿越和爆炸路径线属于独立验收项。
- V0.7 的命名原生视图 `Service Exploded` 与原 21 步爆炸配置共存，可在 SolidWorks 重开后使用。两个预览采用同一读回比例，侧向服务视角更容易区分后侧端盖。原等轴测适合观察齿轮端面。
- V0.8 仅在内部增量作业中启用新的布局、图签和气泡优化。旧版 schema 和 MCP 执行入口保持原能力范围，标准作业不必迁移。制造级校核按验收报告的能力边界执行。
