# SolidWorks V0.5 齿轮工作流

适用于本机 SolidWorks 2014 SP0（COM 22.0.0）的外齿轮候选。用户提供齿数、法向模数与压力角、螺旋角和旋向、齿宽、轴孔与所需键槽。正角与负角分别产生相反端面扭转，零角进入直齿拉伸。输入的长度单位为 mm，`--phase` 为弧度。

```powershell
python -B scripts/gear_v05.py Stage1Gear 48 -20 32.05 --key 10 --phase 3.0761428066400054
python -B scripts/gear_v05.py SpurRegression 24 0 20 --width 12
```

可选参数 `--module`、`--pressure`、`--width`、`--key`、`--key-depth`。`--seed-only` 用于单齿试制，成果需单独标识。单齿截面按渐开线取样，段间线性连接，轮芯与过渡区存在实体重叠。原生齿根暂采用近似过渡，轴孔和键槽保留为可编辑特征。超出实际验收条件的规格需要单独验证。

命令仅附着到启动前观察到的 COM PID、版本和空文档。互斥锁确保同一会话不并发。每次生成独立的 `outputs/v0.5/gear/run-*` 路径和 `native.json`。重开后回读两个端面的齿顶点总数和角位置，核对齿数、相位、旋向、齿宽、轴孔、特征状态和单有效实体。故障时留存阶段及 HRESULT；180 秒停止等待并先核查会话。重试前应保留成功件并定位单项，避免重复运行同一失败命令。

已实测条件为法向模数 2.5 mm、压力角 20°，19、20、48、57 齿的 ±20° 斜齿，齿宽 20 mm，24 齿直齿，齿宽 12 mm。未宣称硬件标准、轮齿强度、根部应力、加工级齿廓、或全部候选参数组合已验证。 [第三方资料](../THIRD_PARTY_LICENSES.md)
