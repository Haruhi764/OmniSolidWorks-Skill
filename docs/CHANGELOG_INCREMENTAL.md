# SolidWorks V0.6–V0.8 增量候选

## V0.6

- 原子状态、版本与输入哈希、排他原生执行、超时与故障隔离。增加只读状态入口和验证后发布。
- 实机在 2014 SP0 中创建、测量、保存并重开一个原生圆柱，复用用户宿主并安全关闭作业文档。真实宿主故障未注入，恢复边界见验收报告。

## V0.7

- 接入逐步扫掠 AABB 代理和有界相机、距离候选比较。以 V0.5 原生实测数据为输入，保留更优的原距离、折合约束与全部爆炸步骤。
- 原生服务视角和同尺度前后预览通过重开。49 件折合零实体干涉，终态 1,176 对包络无重叠。初始配合包络和潜在扫掠交叠独立记录。

## V0.8

- 增量入口加入实测视图范围排版、关联见证尺寸、引线锚点双栏分配和原生标题栏字段检查。实际支持与实机结果见本轮验收报告。
